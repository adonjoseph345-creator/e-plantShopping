# Paradise Nursery Shopping Application

## Project Name: e-plantShopping (Paradise Nursery)

**Paradise Nursery** is an online plant shopping application built using React and Redux Toolkit. Users can browse a wide variety of houseplants categorized into groups such as Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, and Low Maintenance plants.

### Features
- **Landing Page**: Welcomes users to Paradise Nursery with company background information and a "Get Started" button.
- **Product Listing Page**: Displays houseplants organized by category, each featuring a thumbnail image, name, description, price, and an "Add to Cart" button that disables once added.
- **Navigation Bar**: Accessible across the Product Listing and Shopping Cart pages with links to Home, Plants, and the Shopping Cart with a live item quantity badge.
- **Shopping Cart Page**: Allows users to view added plants, adjust item quantities (`+` / `-`), remove items, view individual item subtotals and total cart amount, continue shopping, or proceed to checkout.
